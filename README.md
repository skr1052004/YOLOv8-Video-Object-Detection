# 🎯 YOLOv8 Real-Time Video Object Detection

An end-to-end Computer Vision pipeline built using **YOLOv8** and **Python** to perform real-time object detection on high-definition video streams.

---

## 🚀 Features
* **State-of-the-Art Detection:** Powered by Ultralytics YOLOv8.
* **Video Pipeline Processing:** Handles high FPS videos (1080p @ 50fps) and re-encodes formats via `ffmpeg`.
* **Interactive UI:** Embedded video player with dark mode styling for clean demo visualization.

---

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Computer Vision:** `ultralytics` (YOLOv8), `opencv-python`
* **Video Encoding:** `ffmpeg`
* **Environment:** Google Colab / Jupyter Notebook
